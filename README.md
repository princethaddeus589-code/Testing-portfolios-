# Portfolia

A React + Vite portfolio builder frontend.

## Run locally

1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown in the terminal.

## Deploy to Vercel

Import this project from GitHub. Use the Vite preset, build command `npm run build`, and output directory `dist`.

## Authentication note

Sign-in and sign-up screens are UI previews only. They do not create or verify real accounts until you connect a secure backend/auth provider. Never store passwords in frontend code.
